How it decides

Why it is called a pack

Name-matching scanners drown you in false alarms. Wolf Pack keeps finding and deciding apart.

01 · scoutsFind everything

Each scout reads one kind of source and over-reports on purpose.

02 · denCheck the evidence

Comments, docs, logs and deny-lists are rejected, with the reason kept.

03 · alphaDecide what matters

Ranks by exposure and how long the data must stay secret.

Running it

Run it where your code already is

One command and one runtime dependency, on Windows, macOS and Linux. It opens network connections only to the endpoints you name.

On a laptop

Python 3.11+, wheel from the latest release.

pip install wolfpack_cbom-1.4.1-py3-none-any.whl
wolfpack scan ./payments-api

In a container

Build from the wolf-pack folder; results land beside the code.

docker build -t wolfpack wolf-pack
docker run --rm -v "$PWD:/scan" wolfpack

In GitHub Actions

Code scanning alerts, and a build that stops on new problems.

- uses: QubitMan-hub/PQCsuite/wolf-pack@wolf-pack-v1.4.1
  with:
    fail-on: critical

Set it up once

A .wolfpack.toml keeps every run the same. Against a baseline, only cryptography added since the last release fails the build.

exclude    = ["generated", "*.min.js"]
fail_on    = "high"
shelf_life = 15     # years the data stays secret
migration  = 6      # years your migration takes
tls        = ["api.example.com:443"]

[policy]
profiles = ["nist-ir-8547"]

Limits

Good to know

Every finding carries its evidence and a confidence, so you can see why it is there. These are the cases where you should look twice.

  • Python is fully parsed, and so are JavaScript, TypeScript, Java and Go with the crawler extra. Other languages use rules: names passed through one function or joined from literals are followed, but values that travel further, or come from input at runtime, can be missed.
  • Cryptography written by hand, with no library call or algorithm name, is found only when it uses a well-known constant.
  • An algorithm found in a binary is built into it, which does not always mean it is used.
  • A traffic capture shows only the handshakes it contains; TLS 1.3 hides the server certificate, so capture a live probe too.
  • Fixes name the first library releases with the feature. Check them against the versions you can deploy.
  • The year a quantum computer could break RSA is an assumption you set, 2035 by default, not a prediction.
