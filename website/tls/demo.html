How to read it

Steps 1 to 3
A private authority issues the edge a certificate, an ordinary web server starts, and the edge starts in front of it.
Step 4
A post-quantum client asks for the page. The key exchange line is the group that was negotiated, and the certificate line is the signature algorithm the edge presented.
Step 5
A client that only knows classical key exchange tries the same and is refused. There is no fallback to a key exchange a future quantum computer could break.

Run it yourself

acxelin-tls try

Then set up Acxelin TLS to put an edge in front of your own service.
