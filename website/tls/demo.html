How to read it

Each frame is one event, in the order it happened, and the tree under it shows what each side presented and negotiated. Frames 1 to 3 set the scene: a private authority issues the edge a certificate, an ordinary web server starts, and the edge starts in front of it.

Frame 4 is the post-quantum client: its key exchange is the group that was negotiated, its certificate the signature the edge presented. Frame 5 is a client that knows only classical key exchange. It is refused, and nothing falls back to a key exchange a future quantum computer could break.
