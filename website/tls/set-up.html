Set up Acxelin TLS

It needs Python 3.11 to 3.14 and OpenSSL 3.5 or newer. You do not need another Acxelin product.

  1. Install

    pip install ./core ./products/tls
acxelin-tls doctor

    doctor says whether this machine can do post-quantum TLS. Debian 13 ships OpenSSL 3.5, and the container image has it. If OpenSSL 3.5 is installed elsewhere, point ACXELIN_OPENSSL at its folder. From a release, unpack its wheelhouse and run pip install --no-index --find-links wheelhouse acxelin-tls.

  2. See it work

    acxelin-tls try

    A one-minute tour with nothing to set up. The demo page shows its real output.

  3. Create the authority and a certificate

    Use the console (next step), or the command line:

    acxelin-tls ca init --name "Example Root CA" --dir pki
acxelin-tls ca issue server web.example.com --dir pki --out web

  4. Put the edge in front of a service

    acxelin-tls edge --listen 0.0.0.0:8443 --target 127.0.0.1:8080 \
  --cert web/chain.pem --key web/key.pem

    Add --require-client-cert --ca pki/ca.crt --crl pki/crl.pem for mutual TLS. For several routes, write an edge.toml and run acxelin-tls edge --config edge.toml. Check it first with acxelin-tls doctor --config edge.toml.

  5. Open the console

    acxelin-tls console

    Your browser opens already signed in. Create the certificate authority, give its key a passphrase, then issue and revoke certificates, add running edges to see their policy, test a connection, and read the health checks. The console keeps the passphrase in memory only, so it asks again after a restart.

    On a remote server

    The console only listens on the machine it runs on. Forward a port, then ask the running console for a fresh link:

    ssh -L 8900:127.0.0.1:8900 server
acxelin-tls console link --port 8900

    Run the second command in that SSH session and open the address it prints on your laptop.

    In Docker

    docker build -f products/tls/deploy/Dockerfile -t acxelin-tls .
docker run -p 127.0.0.1:8900:8900 acxelin-tls console --no-browser
docker exec -it NAME acxelin-tls console link

    In Kubernetes

    The chart does not expose the console. Forward its port, then run console link through kubectl exec. The chart's notes print both commands.

  6. Keep it running

    Run acxelin-tls ca maintain --dir pki every day. The systemd units, the Helm chart and the sidecar example are in products/tls/deploy.
